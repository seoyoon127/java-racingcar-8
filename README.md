# 프리코스 2주차 - 자동차 경주

# 구현할 기능 목록

## 입력 및 검증

- [ ] 자동차 이름 문자열을 입력 받는다.

  - [ ] 빈 문자열이 아닌지 확인한다.

  - [ ] 이름이 5자 이하인지 확인한다.

  - [ ] 중복된 이름이 있는지 확인한다.

- [ ] 이동 횟수를 입력 받는다.

  - [ ] 양의 정수가 맞는지 확인한다.

## 도메인 로직

### Car

- [ ] 이름, 전진 횟수를 필드로 가진다.

- [ ] 전진하는 기능

- [ ] 이름, 전진 횟수를 반환하는 기능

### Cars

- [ ] 자동차 리스트를 필드로 가진다.

- [ ] 우승자를 구하는 기능

- [ ] 자동차 리스트를 반환하는 기능

## 유틸리티

- [ ] 무작위 값을 구한 후 4 이상 여부를 반환하는 기능

## 출력

- [ ] 자동차 이름과 이동거리를 출력한다.

- [ ] 최종 우승자를 출력한다.

- [ ] 우승자가 여러 명일 경우, 쉼표(,)를 이용하여 구분한다.

## 예외 처리

- [ ] 사용자가 잘못된 값 입력 시 IllegalArgumentException을 발생 후 종료시킨다.

## 테스트

- [ ] 빈 문자열이 아닌지 테스트

- [ ] 이름이 5자 이하인지 테스트

- [ ] 이름이 중복인지 테스트

- [ ] 이동횟수가 양의 정수인지 테스트

- [ ] 우승자를 구하는 기능 테스트

- [ ] 잘못된 입력 시 IllegalArgumentException 발생하는지 테스트
